# Arcana resource pack

Server resource pack for an Arcana (magic plugin) Minecraft server. Currently it redraws the eight
ritual planet symbols (☉ ☽ ☿ ♀ ♂ ♃ ♄ ✶) at the same width as digits so ritual diagrams line up.

Build: `python build_pack.py` (needs Pillow). The zip is attached to each release.
